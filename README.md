# تطبيق «استثمار النتائج» لنظام أندرويد (APK)

هذا المشروع هو نفس برنامج الحاسوب (Electron) بعد تحويله إلى تطبيق أندرويد باستعمال Capacitor.

## الطريقة الأسهل: بناء الـ APK مجاناً على GitHub (بدون تثبيت أي شيء)

1. أنشئ حساباً مجانياً على https://github.com ثم أنشئ مستودعاً جديداً (New repository) باسم `nataij-android`.
2. ارفع كل محتويات هذا المجلد إلى المستودع (زر **Add file ← Upload files**، ثم اسحب كل الملفات والمجلدات،
   **بما فيها المجلد المخفي `.github`**). إن لم يظهر المجلد `.github` عندك فأنشئ الملف يدوياً بالمسار
   `.github/workflows/build-apk.yml` وانسخ إليه محتوى الملف الموجود في هذا المشروع.
3. افتح تبويب **Actions** ← سيبدأ البناء تلقائياً (أو اضغط **Build Android APK ← Run workflow**). يستغرق نحو 5–10 دقائق.
4. عند انتهائه افتح عملية البناء الأخيرة، وفي أسفل الصفحة (Artifacts) نزّل **nataij-apk** (ملف مضغوط يحتوي `app-debug.apk`).
5. انقل `app-debug.apk` إلى الهاتف وافتحه. إن طلب الهاتف ذلك فعّل **«السماح بالتثبيت من هذا المصدر»**.

## البناء على حاسوبك (اختياري)
المتطلبات: Node.js 22، JDK 21، Android Studio (أو Android SDK).
```
npm install
npm run build:android
cd android
./gradlew assembleDebug        (على ويندوز: gradlew.bat assembleDebug)
```
الملف الناتج: `android/app/build/outputs/apk/debug/app-debug.apk`

## ما الذي تغيّر مقارنة بنسخة الحاسوب؟
- **الواجهة**: صارت متجاوبة مع الهاتف (شريط تنقّل سفلي، بطاقات بعمودين، معاينة التقرير A4 مصغّرة تلقائياً).
- **استيراد Excel**: يعمل عبر منتقي الملفات في أندرويد.
- **تصدير Excel والنموذج الجاهز**: يُنشأ الملف ثم تظهر نافذة المشاركة (احفظه في «الملفات» أو أرسله عبر واتساب/البريد…).
- **التقرير PDF**: يفتح نافذة الطباعة في أندرويد؛ اختر منها **«حفظ بصيغة PDF»** أو اطبع مباشرة.
- **البيانات**: تُحفظ داخل التطبيق على الهاتف. حذف التطبيق أو مسح بياناته يمحوها؛ لذلك خذ نسخة احتياطية دورياً عبر «تصدير إلى Excel».

## الصور
لم تكن الصور `assets/logo.png` و`assets/quran.png` ضمن الملفات المرسلة، فتم توليد شعار بسيط للتطبيق (`src/assets/logo.png`).
لاستعمال شعارك أنت: ضع `logo.png` و`quran.png` في المجلد `src/assets/` (وإن أردت أيقونة التطبيق نفسها فاستبدل الملفات
في `resources/` أو أعد توليدها). الملف `.ico` المرفق هو أيقونة برنامج آخر (The Unarchiver) فلم أستعمله.

## تعديل البرنامج لاحقاً
المصدر الرئيسي هو `src/index.html`. بعد أي تعديل ارفعه إلى GitHub فيُبنى APK جديد تلقائياً.
